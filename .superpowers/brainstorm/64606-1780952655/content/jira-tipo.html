¿Qué versión de Jira usás?

Esto afecta cómo nos conectamos a la API

A

Jira Cloud

Tu URL es algo como miempresa.atlassian.net. API moderna REST v3, autenticación con API token.

B

Jira Server / Data Center

Jira instalado en servidores propios. URL interna, autenticación por usuario/contraseña o token.

C

No estoy seguro

Puedo ayudarte a detectarlo con la URL que usás para acceder a Jira.
